# sun-kb-home

把 Obsidian 的知识库浏览拆成两级：首页是知识库卡片墙，点开某张卡片后只显示该知识库的文件树。

[English](README.md)

## 为什么

Obsidian 默认左侧是一整棵文件树，所有项目、所有库的内部分支都挤在一个面板里，展开后无限长。sun-kb-home 把它拆成两级：

```
知识库卡片  →  某个知识库的文件树
  （首页）          （点击卡片后）
```

分组是真实文件夹。笔记仍然是普通的 Markdown 文件，插件不会把内容复制进数据库。

## 核心概念

| 概念 | 说明 |
| --- | --- |
| 知识库 | 分组文件夹的**直接子文件夹**；或根目录下未登记为分组的文件夹（未分组知识库）。 |
| 分组 | vault 根目录下的一层**真实文件夹**。新建、改名、移动、删除分组都会真实操作文件夹。 |
| 树 | 单个知识库的原生风格文件树。 |

`data.json` 只保存分组登记、排序和显示覆盖；文件内容仍然在 vault 里。

## 功能

### 卡片墙

- 每个知识库一行紧凑卡片：图标、名称、文档数。
- 三种卡片外观：**线框**、**浅灰背景**、**分隔线**（设置 → sun-kb-home → 卡片样式）。
- 被隐藏的文件夹默认不会作为卡片出现；开启「显示被隐藏的文件」后会重新出现在卡片墙。
- 通过卡片上的 `⋯` 或右键菜单新建、改名、换图标、移入分组、删除。

### 分组是真实文件夹

- **新建分组**会在 vault 根目录创建一个真实文件夹。
- 把卡片拖进另一个分组，就是把这个知识库文件夹移进那个分组。
- 分组改名 / 删除就是文件夹改名 / 删除。删除分组会先把组内内容移回 vault 根目录，不会删除笔记。
- 只有分组的**直接子文件夹**会成为知识库卡片。直接放在分组文件夹里的笔记 / 文件留在原生文件树里，不会变成卡片。

### 拖拽

- **卡片**：拖动排序。拖动时显示竖向插入线：落在卡片左半插到它前面，落在右半插到它后面。
- **分组**：拖动分组标题调整分组顺序，上/下沿显示插入线。
- **树**：同级排序、拖进文件夹、落在其他条目的上/下沿（跨文件夹移入并插到该位置）、拖回库根标题。
- 文件夹行上下 30% 出插入线，中间 40% 显示明确的「移入」高亮。
- 卡片拖回自己所在分组的空白处是空操作，不会整块高亮。
- 拖动时在折叠文件夹上停约 1 秒会自动展开。
- 移动时遇到重名会自动加序号避让。

### 原生文件浏览器

- 自定义顺序、置顶、隐藏（手动或 glob 规则），以及按自定义 / 名称 / 创建时间 / 修改时间排序。
- 只有一份数据：原生文件浏览器、单库树、知识库卡片墙共用 `data.json` 里的顺序 / 置顶 / 隐藏状态。
- 未开启「显示被隐藏的文件」时，被隐藏的根目录文件夹不会作为知识库卡片出现。
- 原生文件浏览器支持多选拖拽、边缘自动滚动、拖入文件夹。

### 提示块

- `:::note`、`:::tip`、`:::info`、`:::warning`、`:::danger`。
- 支持自定义标题（`:::tip 标题` 或 `:::tip[标题]`）、折叠变体（`:::tip+` / `:::tip-`）和嵌套。
- 实时预览和阅读视图都会渲染，两边可以分别开关。
- 正文里的行内 Markdown 正常工作。

## 分组结构

```
vault/
├─ 工作/                  ← 分组（真实文件夹）
│  ├─ 中医手册/           ← 知识库（卡片）
│  └─ 编程/               ← 知识库（卡片）
├─ 生活/                  ← 分组
│  └─ 旅行/               ← 知识库
└─ 杂项/                  ← 根目录下未登记为分组的文件夹 = 未分组知识库
```

- 根目录文件夹只有在插件里登记后才会成为分组（点「新建分组」，或设置 → 分组管理 →「把现有文件夹设为分组」）。其他根目录文件夹都是未分组知识库。
- 只有直接子文件夹才是知识库；更深的层级属于该知识库的内部目录。
- 删除分组会把它的直接内容移回 vault 根目录，再删除空的分组文件夹；不会递归删除笔记。移动失败时会保留分组并提示。

## 安装

**从 Obsidian 社区插件安装：** 搜索 **sun-kb-home**，安装并启用。

**手动安装：**

1. 从 Releases 下载 `sun-home-<版本>-plugin.zip`，或从源码构建。
2. 把 `main.js`、`manifest.json`、`styles.css` 复制到 `<vault>/.obsidian/plugins/sun-home/`。
3. 在设置 → 第三方插件中启用 **sun-kb-home**。

手动复制后，在第三方插件里用开关启用一次，Obsidian 就会把它登记进 `community-plugins.json`，之后重启不会掉启用状态。Obsidian 运行期间不要手动编辑这个文件。

需要 Obsidian **1.7.2** 或更高版本。

旧 `kb-home` 插件目录或旧虚拟分组的配置会在首次加载时自动迁移。如果当时点了「稍后」，命令面板里仍有 **迁移旧分组到真实文件夹**。

## 使用

1. 从左侧 ribbon（书本图标）或命令面板打开知识库列表。
2. 用顶部按钮新建分组 / 知识库，或在设置里把现有根目录文件夹设为分组。
3. 拖动卡片排序，或把卡片拖到其他分组。
4. 点击卡片进入该知识库的树；点「← 全部知识库」返回。
5. 树顶部的工具条可以新建笔记 / 文件夹、切换整个知识库的排序方式、折叠 / 展开全部、定位当前笔记。
6. 右键条目可以打开 / 在新标签页打开、重命名、删除、复制路径、在系统资源管理器中显示、置顶、隐藏、排序。

## 设置

- **启动时自动打开知识库列表**：默认开启。
- **卡片样式**：线框、浅灰背景、分隔线。
- **重新扫描知识库**：在 Obsidian 外部新建文件夹后刷新。
- **分组管理**：查看分组对应的真实文件夹、把现有根目录文件夹设为分组、删除分组。
- **排序与隐藏**：显示被隐藏的文件、逐个管理已隐藏项、新建文件插入位置、增删时保持顺序、gitignore 风格隐藏规则、调试日志。
- **提示块**：实时预览和阅读视图两个独立开关。

## 命令

在命令面板里搜索 `sun-kb-home`：

- **打开知识库列表**
- **打开当前笔记所在知识库的目录**
- **显示 / 隐藏被隐藏的文件**
- **迁移旧分组到真实文件夹**（只有很旧的配置才需要）

左侧栏有两个 ribbon 图标对应前两个命令。

## 已知限制

- 分组只有一层，不支持嵌套分组。
- 直接放在分组文件夹里的文件不会成为知识库卡片，但仍可在原生文件树里打开。
- 以 `.` 开头的文件夹、以及命中隐藏规则的文件夹不会出现在列表里。
- 重命名分组或知识库不会改写 glob 隐藏规则里的旧路径，需要手动调整。
- 移动 / 删除分组会真实操作文件夹。Obsidian 会更新内部链接，但外部工具、绝对路径或在 Obsidian 之外创建的引用可能需要手动修正。
- 提示块：阅读视图里，如果块内用空行隔开表格 / 小标题 / 代码块，这些元素可能落在框外；实时预览没有这个问题。提示块标题里的行内 Markdown 在实时预览中渲染，在阅读视图里按纯文本显示。
- 阅读视图的提示块渲染会改写 Obsidian 已渲染的 DOM；其他同样改写预览 DOM 的插件可能与之互相影响。

## 从源码构建

```bash
npm install --ignore-scripts
npm run build        # 生产构建，产出 main.js
npm run dev          # 监听模式
npm run typecheck    # TypeScript 检查
```

`main.js` 生成在项目根目录，和 `manifest.json`、`styles.css` 一起构成完整插件。

Windows 上 `--ignore-scripts` 用于避开 esbuild postinstall 的 `EBUSY`，平台包仍会正常安装。
